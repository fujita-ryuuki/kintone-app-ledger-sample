# kintone アプリ設計書 — 出力サンプル

kintone のドメイン内の全アプリを走査して、設定を1つの Markdown ファイルに書き出すプラグインを作っています。
そのプラグインが実際に吐いた出力を、そのまま1本置いてあります。

## 中身

- [`sample-with-diff.md`](./sample-with-diff.md) — 19アプリぶん、1,501行

架空の会社（`sample-corp.cybozu.com`）の kintone 環境を作って走査したものです。
実在の企業・個人のデータは含まれていません。

見どころは冒頭の「前回からの変更」です。
2回目以降の走査では、前回の記録と突き合わせて**変わった箇所だけを先頭に並べます。**
このサンプルでは、フィールドの追加・削除、ラベル変更、一覧の追加、アプリの追加、
そして**アクセス権の変更**が並んでいます。

「誰が変更したか」は判定していません。変更者を特定する場合は kintone の監査ログを見てください。
分からないことを分かるように書くのはやめました。

## 1行目の「社外秘」について

出力の先頭に注意書きが入るのはプラグインの仕様です。
本物の環境で走査すると、権限設定と担当者名が1ファイルに集まります。取り扱いには注意してください。

## これは何ではないか

サイボウズ株式会社の公式製品ではありません。
出力内容は走査した時点の kintone REST API の応答に基づきます。
